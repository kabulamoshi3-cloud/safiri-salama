📋 SETUP (First Time)
═══════════════════════════════════════════════════════════════════════

1. Install dependencies:
   .\setup-tracking.ps1

2. Add Google Maps API Key:
   Edit: services\tracking-service\.env
   Add: GOOGLE_MAPS_API_KEY=your_key_here
   Get key: https://console.cloud.google.com/

3. Setup database:
   cd services\api-gateway
   npm run migrate

4. Start Redis:
   redis-server
   OR
   docker run --name dalasmart-redis -p 6379:6379 -d redis:7

═══════════════════════════════════════════════════════════════════════
🚀 START ALL SERVICES
═══════════════════════════════════════════════════════════════════════

Quick Start:
   .\start-all-services.ps1

Manual Start:
   Terminal 1: cd services\tracking-service && npm run dev
   Terminal 2: cd services\api-gateway && npm run dev
   Terminal 3: cd apps\web-platform && npm run dev
   Terminal 4: cd apps\driver-dashboard && npm run dev (optional)

🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════

Problem: Redis not running
   Solution: redis-server
   OR: docker run --name dalasmart-redis -p 6379:6379 -d redis:7

Problem: Port already in use
   netstat -ano | findstr :3001
   taskkill /PID <PID> /F

Problem: Google Maps API error
   1. Check .env has correct key
   2. Enable Directions API in Google Cloud
   3. Restart tracking service

Problem: Route not showing
   1. Check Google Maps API key
   2. Check browser console (F12)
   3. Verify Directions API enabled

Problem: No ETA notifications
   - Normal! Notifications only show if ETA changes by 5+ minutes
   - Traffic monitoring runs every 2 minutes
   - Wait 2-4 minutes for first check
