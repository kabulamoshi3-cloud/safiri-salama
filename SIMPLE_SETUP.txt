DALASMART SIMPLE SETUP GUIDE
=============================

STEP 1: Create PostgreSQL Database
-----------------------------------
Option A - Using psql command line:
  psql -U postgres
  CREATE DATABASE dalasmart;
  \q

Option B - Using pgAdmin GUI:
  1. Open pgAdmin
  2. Right-click "Databases" -> Create -> Database
  3. Name: dalasmart
  4. Click Save


STEP 2: Create .env File
-------------------------
Create this file: services\api-gateway\.env

Copy this content:
-----------------
DATABASE_URL=postgresql://postgres:YOUR_PASSWORD@localhost:5432/dalasmart
JWT_SECRET=dalasmart-secret-key-change-in-production
PORT=3000
NODE_ENV=development
CORS_ORIGIN=http://localhost:5173;http://localhost:5174
-----------------

Replace YOUR_PASSWORD with your postgres user password!


STEP 3: Run Database Migrations
--------------------------------
Open PowerShell and run:

cd "c:\project\INF 319\dalasmart\services\api-gateway"
npm run migrate
npm run seed


STEP 4: Start All Services
---------------------------
Terminal 1 (Backend):
  cd "c:\project\INF 319\dalasmart\services\api-gateway"
  npm run dev

Terminal 2 (Driver Dashboard):
  cd "c:\project\INF 319\dalasmart\apps\driver-dashboard"
  npm run dev

Terminal 3 (Web Platform):
  cd "c:\project\INF 319\dalasmart\apps\web-platform"
  npm run dev


STEP 5: Test It Works
----------------------
Open browser:
  http://localhost:3000/health  (should show "healthy")
  http://localhost:5173         (Driver Dashboard)
  http://localhost:5174         (Web Platform)


THAT'S IT!
==========
Everything is ready - just follow these 5 steps!
