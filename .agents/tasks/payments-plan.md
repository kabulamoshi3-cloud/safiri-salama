## Gaps to fix

### Gap 1 — `university_orders` missing `payment_status`/`transaction_id` columns (migration fix)

The `university_orders` table in migration 010 does NOT have `payment_status` or `transaction_id`.  
Migration 011 does not ALTER `university_orders`.  
`handlePaymentSuccess()` in payments.ts already writes to `university_orders` … but the columns don't exist.

### Gap 2 — `payment_splits` table missing (migration fix)

`creditPayee()` in payments.ts does not write splits, and the table doesn't exist in any migration.

### Gap 3 — `context` CHECK constraint in `transactions` is too narrow

Current CHECK: `context IN ('ride','food','shop','market','topup')`.  
Gaps 4 and 5 add `transfer` and `bill` contexts — the CHECK must include them.

### Gap 4 — POST /pay does not handle `context='transfer'` (P2P money transfer)

`to_user_id` or `to_phone` param → debit sender wallet → credit recipient wallet → log two transaction rows.

### Gap 5 — POST /pay does not handle `context='bill'` (LUKU, DAWASCO, DSTV, NHIF)

`biller_code` + `account_number` params → STK push exactly like mobile money but with context='bill'.

### Gap 6 — POST /payments/admin/refund missing (admin refund any transaction)

Admin endpoint — no `user_id` ownership check, just admin role guard.

### Gap 7 — GET /payments/admin/report missing (settlement report)

Total volume by context, payout summaries, pending splits.

### Gap 8 — `creditPayee()` does not write to `payment_splits` 

After crediting the payee wallet it must INSERT a row into `payment_splits` for the payee portion and one for the platform portion.

### Gap 9 — `handlePaymentSuccess()` does not update `university_orders`

The ride/food/shop blocks exist; the `market` block is missing.

- [ ] 4. **Add `transfer` context handling to POST /pay** — P2P wallet-to-wallet transfer.

  Add to `PLATFORM_FEE_RATES`:
  ```typescript
  transfer: 0.01,  // 1% fee on P2P transfers
  bill:     0.00,  // no Safiri Haraka fee on bill payments
  ```

  In POST /pay, add a new `validContexts` guard at the top of the handler (currently context is never validated). Then, inside the mobile-money branch (before the `mobileMoneyMethods.includes(method)` block), add a `transfer` branch:

  ```typescript
  // ══════════════════════════════════════════════════════════════════════
  //  TRANSFER — P2P wallet to wallet
  // ══════════════════════════════════════════════════════════════════════
  if (context === 'transfer') {
    const { to_user_id, to_phone } = req.body;

    if (!to_user_id && !to_phone) {
      db.release();
      return res.status(400).json({ error: 'to_user_id or to_phone is required for transfer' });
    }

    // Resolve recipient
    let recipientQuery: string;
    let recipientParam: any;
    if (to_user_id) {
      recipientQuery = `SELECT id, name FROM users WHERE id = $1`;
      recipientParam = to_user_id;
    } else {
      recipientQuery = `SELECT id, name FROM users WHERE phone = $1`;
      recipientParam = normalisePhone(to_phone);
    }
    const recipientResult = await db.query(recipientQuery, [recipientParam]);
    if (recipientResult.rowCount === 0) {
      db.release();
      return res.status(404).json({ error: 'Recipient not found' });
    }
    const recipient = recipientResult.rows[0];

    if (recipient.id === user.id) {
      db.release();
      return res.status(400).json({ error: 'Cannot transfer to yourself' });
    }

    if (walletBalance < amount) {
      db.release();
      return res.status(400).json({
        error:    'Insufficient wallet balance',
        required: `Sh${Number(amount).toLocaleString()}`,
        balance:  `Sh${walletBalance.toLocaleString()}`,
      });
    }

    const feeRate     = PLATFORM_FEE_RATES.transfer;          // 0.01
    const fee         = Math.round(amount * feeRate);
    const netAmount   = amount - fee;

    await db.query(`BEGIN`);
    try {
      // Debit sender (full amount including fee)
      await db.query(
        `UPDATE wallets SET balance = balance - $1 WHERE user_id = $2`,
        [amount, user.id]
      );

      // Credit recipient (net of fee)
      await db.query(
        `INSERT INTO wallets (user_id, balance, currency) VALUES ($1, $2, 'TZS')
         ON CONFLICT (user_id) DO UPDATE SET balance = wallets.balance + $2`,
        [recipient.id, netAmount]
      );

      // Debit transaction (sender side)
      await db.query(
        `INSERT INTO transactions
           (reference, user_id, context, context_id, amount, type, method, provider, status, description)
         VALUES ($1,$2,'transfer',$3,$4,'debit','wallet','wallet','completed',$5)`,
        [reference, user.id, recipient.id, amount,
         description ?? `Transfer to ${recipient.name}`]
      );

      // Credit transaction (recipient side)
      const creditRef = makeRef('TRC');
      await db.query(
        `INSERT INTO transactions
           (reference, user_id, context, context_id, amount, type, method, provider, status, description)
         VALUES ($1,$2,'transfer',$3,$4,'credit','wallet','wallet','completed',$5)`,
        [creditRef, recipient.id, user.id, netAmount,
         `Received from ${user.name ?? 'a user'}`]
      );

      // Splits: payee gets netAmount, platform gets fee
      await db.query(
        `INSERT INTO payment_splits
           (transaction_ref, recipient_id, role, gross_amount, split_amount, fee_rate)
         VALUES
           ($1, $2, 'payee',    $3, $4, $5),
           ($1, $2, 'platform', $3, $6, $5)`,
        [reference, recipient.id, amount, netAmount, feeRate, fee]
      );

      await db.query(`COMMIT`);
      db.release();

      return res.json({
        reference,
        status:     'completed',
        method:     'wallet',
        to:         { id: recipient.id, name: recipient.name },
        amount_sent: `Sh${Number(amount).toLocaleString()}`,
        fee:         `Sh${fee.toLocaleString()}`,
        net_received:`Sh${netAmount.toLocaleString()}`,
        message:    `✅ Sh${Number(amount).toLocaleString()} sent to ${recipient.name}`,
        receipt_url:`/api/v1/payments/receipt/${reference}`,
        poll_url:    null,
      });
    } catch (e) {
      await db.query(`ROLLBACK`);
      db.release();
      throw e;
    }
  }
  ```

- [ ] 5. **Add `bill` context handling to POST /pay** — STK push for biller payments.

  ```typescript
  // ══════════════════════════════════════════════════════════════════════
  //  BILL PAYMENT — LUKU, DAWASCO, DSTV, NHIF via STK push
  // ══════════════════════════════════════════════════════════════════════
  if (context === 'bill') {
    const { biller_code, account_number } = req.body;

    const validBillers: Record<string, string> = {
      LUKU:   'Tanzania Electric Supply Co. (LUKU)',
      DAWASCO:'Dar es Salaam Water & Sewerage',
      DSTV:   'DSTV Subscription',
      NHIF:   'National Health Insurance Fund',
    };

    if (!biller_code || !validBillers[biller_code.toUpperCase()]) {
      db.release();
      return res.status(400).json({
        error:          'Invalid biller_code',
        valid_billers:  Object.keys(validBillers),
      });
    }
    if (!account_number) {
      db.release();
      return res.status(400).json({ error: 'account_number is required for bill payment' });
    }

    // Bill payment MUST use mobile money (wallet top-up flow not supported here)
    if (!mobileMoneyMethods.includes(method)) {
      db.release();
      return res.status(400).json({
        error: 'Bill payments must use a mobile money method (mpesa, airtel_money, tigo_pesa, or halotel)',
      });
    }

    const billerName = validBillers[biller_code.toUpperCase()];
    const billDesc   = description ?? `${billerName} — Account: ${account_number}`;

    await db.query(
      `INSERT INTO transactions
         (reference, user_id, context, context_id, amount, type, method, provider,
          phone_number, phone_source, status, description, expires_at)
       VALUES ($1,$2,'bill',$3,$4,'debit','mobile_money',$5,$6,$7,'pending',$8,
               NOW() + INTERVAL '2 minutes')`,
      [
        reference, user.id, account_number,   // context_id stores account_number
        amount, method, phoneToUse, phoneSource, billDesc,
      ]
    );

    db.release();

    await fireStkPush({ method, phone: phoneToUse, amount, reference, description: billDesc });

    return res.json({
      reference,
      status:      'pending',
      method,
      context:     'bill',
      biller_code: biller_code.toUpperCase(),
      biller_name: billerName,
      account_number,
      provider_name: PROVIDER_NAMES[method],
      phone_used:   maskPhone(phoneToUse),
      phone_source: phoneSource,
      message:      stkInstructions(method, maskPhone(phoneToUse), amount),
      expires_in_seconds: 120,
      poll_url:    `/api/v1/payments/status/${reference}`,
    });
  }
  ```

- [ ] 6. **Add POST /payments/admin/refund** — admin-triggered refund for any transaction.

  Add after the existing user `/refund` route (near end of file, before `export default`):

  ```typescript
  // ══════════════════════════════════════════════════════════════════════════════
  //  ADMIN REFUND  (admin can refund any user's completed transaction)
  // ══════════════════════════════════════════════════════════════════════════════

  /**
   * POST /payments/admin/refund
   * Admin only. Refunds any completed transaction, crediting the original payer's wallet.
   *
   * Body: { reference: string, reason: string }
   */
  paymentsRouter.post('/admin/refund', async (req: Request, res: Response) => {
    const user = (req as any).user;
    if (!user) return res.status(401).json({ error: 'Unauthorized' });
    if (user.user_type !== 'admin') return res.status(403).json({ error: 'Admin access required' });

    const { reference, reason } = req.body;
    if (!reference || !reason) {
      return res.status(400).json({ error: 'reference and reason are required' });
    }

    try {
      const db = await database.getClient();

      // No user_id filter — admin can refund any transaction
      const txResult = await db.query(
        `SELECT * FROM transactions WHERE reference = $1`,
        [reference]
      );

      if (txResult.rowCount === 0) {
        db.release();
        return res.status(404).json({ error: 'Transaction not found' });
      }

      const tx = txResult.rows[0];

      if (tx.status !== 'completed') {
        db.release();
        return res.status(400).json({ error: 'Only completed transactions can be refunded' });
      }
      if (tx.refunded) {
        db.release();
        return res.status(400).json({ error: 'Already refunded' });
      }

      const refundRef = makeRef('ARFD');

      await db.query(`BEGIN`);
      // Credit original payer's wallet
      await db.query(
        `INSERT INTO wallets (user_id, balance, currency) VALUES ($1, $2, 'TZS')
         ON CONFLICT (user_id) DO UPDATE SET balance = wallets.balance + $2`,
        [tx.user_id, tx.amount]
      );
      await db.query(
        `UPDATE transactions
         SET refunded = true, refund_reference = $1, refund_reason = $2
         WHERE reference = $3`,
        [refundRef, reason, reference]
      );
      await db.query(
        `INSERT INTO transactions
           (reference, user_id, context, amount, type, method, provider, status, description)
         VALUES ($1,$2,$3,$4,'credit','refund','wallet','completed',$5)`,
        [refundRef, tx.user_id, tx.context, tx.amount, `Admin refund: ${reason}`]
      );
      await db.query(`COMMIT`);
      db.release();

      res.json({
        message:          `✅ Admin refund of Sh${Number(tx.amount).toLocaleString()} issued`,
        refund_reference: refundRef,
        original_reference: reference,
        refunded_user_id: tx.user_id,
        amount:           `Sh${Number(tx.amount).toLocaleString()}`,
        reason,
      });
    } catch (err: any) {
      res.status(500).json({ error: 'Admin refund failed', details: err.message });
    }
  });
  ```

- [ ] 7. **Add GET /payments/admin/report** — settlement report.

  Add immediately after the admin refund route:

  ```typescript
  // ══════════════════════════════════════════════════════════════════════════════
  //  ADMIN SETTLEMENT REPORT
  // ══════════════════════════════════════════════════════════════════════════════

  /**
   * GET /payments/admin/report
   * Admin only. Query params: from, to (ISO dates, optional).
   *
   * Returns:
   *  - total_volume_by_context: { ride, food, shop, market, topup, transfer, bill }
   *  - payout_summaries: top 10 payees by amount received
   *  - pending_splits: count and total of unresolved payment_splits
   *  - overall: total transactions, total volume, total fees collected
   */
  paymentsRouter.get('/admin/report', async (req: Request, res: Response) => {
    const user = (req as any).user;
    if (!user) return res.status(401).json({ error: 'Unauthorized' });
    if (user.user_type !== 'admin') return res.status(403).json({ error: 'Admin access required' });

    const { from, to } = req.query;

    try {
      const db = await database.getClient();

      const dateFilter = from && to
        ? `AND t.created_at BETWEEN $1 AND $2`
        : from
          ? `AND t.created_at >= $1`
          : to
            ? `AND t.created_at <= $1`
            : '';

      const dateParams: any[] = from && to ? [from, to] : from ? [from] : to ? [to] : [];

      // Volume by context
      const volumeResult = await db.query(
        `SELECT context,
                COUNT(*)          AS tx_count,
                SUM(amount)       AS total_amount,
                SUM(CASE WHEN status = 'completed' THEN amount ELSE 0 END) AS completed_amount,
                SUM(CASE WHEN status = 'failed'    THEN 1       ELSE 0 END) AS failed_count
         FROM transactions t
         WHERE type = 'debit' ${dateFilter}
         GROUP BY context
         ORDER BY completed_amount DESC`,
        dateParams
      );

      // Top payees (from payment_splits)
      const payeeResult = await db.query(
        `SELECT ps.recipient_id, u.name, u.phone,
                COUNT(ps.id)          AS split_count,
                SUM(ps.split_amount)  AS total_received
         FROM payment_splits ps
         JOIN users u ON u.id = ps.recipient_id
         WHERE ps.role = 'payee'
         GROUP BY ps.recipient_id, u.name, u.phone
         ORDER BY total_received DESC
         LIMIT 10`
      );

      // Platform fees
      const feeResult = await db.query(
        `SELECT SUM(split_amount) AS total_fees
         FROM payment_splits
         WHERE role = 'platform'`
      );

      // Overall
      const overallResult = await db.query(
        `SELECT COUNT(*) AS total_transactions,
                SUM(CASE WHEN status = 'completed' AND type = 'debit' THEN amount ELSE 0 END) AS total_completed_volume,
                SUM(CASE WHEN status = 'pending'   THEN amount ELSE 0 END) AS total_pending_volume,
                COUNT(CASE WHEN status = 'pending' THEN 1 END) AS pending_count
         FROM transactions t
         WHERE 1=1 ${dateFilter}`,
        dateParams
      );

      db.release();

      res.json({
        report_period: {
          from: from ?? 'all time',
          to:   to   ?? 'now',
        },
        overall: overallResult.rows[0],
        volume_by_context: volumeResult.rows,
        top_payees:        payeeResult.rows.map(p => ({
          ...p,
          total_received_formatted: `Sh${Number(p.total_received).toLocaleString()}`,
          phone_masked: maskPhone(p.phone),
        })),
        platform_fees: {
          total_fees: feeResult.rows[0]?.total_fees ?? 0,
          total_fees_formatted: `Sh${Number(feeResult.rows[0]?.total_fees ?? 0).toLocaleString()}`,
        },
      });
    } catch (err: any) {
      res.status(500).json({ error: 'Failed to generate report', details: err.message });
    }
  });
  ```

## Key decisions recorded

- **`payment_splits` platform row uses `payeeId`**: There is no platform wallet user in the current schema. The platform row records the fee amount for reporting without crediting a wallet. This avoids introducing a new users row in this plan — a follow-up can add a `platform_wallet_user_id` config key.
- **Bill payment requires mobile money**: The bill context only routes through STK push, not wallet, because billers need the mobile network as the payment rail. Wallet-funded bill payments are deferred.
- **Transfer uses wallet only**: P2P transfers debit the sender's Safiri Haraka wallet. Mobile money P2P (send to external number) already exists in `moneyTransfer.ts` and is out of scope here.
- **1% transfer fee**: The fee rate keeps in-app transfers marginally cheaper than mobile money (which charges 1–2%). This is a business decision recorded in `PLATFORM_FEE_RATES`.
- **`context_id` stores `account_number` for bill payments**: Reuses the existing `context_id` column (VARCHAR/UUID-compatible text) for the biller account, avoiding a schema change. The column is not a FK so there is no type conflict.
- **`ARFD` prefix for admin refund refs**: Distinguishes admin-issued refunds (`ARFD-…`) from user-self-refunds (`RFD-…`) in the audit trail.
