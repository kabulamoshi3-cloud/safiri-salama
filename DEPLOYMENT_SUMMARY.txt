================================================================================
                         HOW TO DEPLOY
================================================================================

STEP 1: Android App (30 minutes)
────────────────────────────────
1. Create Google Play account ($25)
2. Build: npm run build:android --mode release
3. Upload APK to Google Play Console
4. Fill app details (screenshots, description, etc.)
5. Submit for review
6. Wait 2-24 hours for approval
7. ✅ Published to Play Store

STEP 2: iOS App (45 minutes)
────────────────────────────
1. Create Apple Developer account ($99/year)
2. Build: xcodebuild archive
3. Upload IPA to App Store Connect
4. Fill app details (screenshots, description, etc.)
5. Submit for review
6. Wait 24-48 hours for approval
7. ✅ Published to App Store

STEP 3: Backend API (2-3 hours)
───────────────────────────────
METHOD A: Using AWS (Recommended)
──────────────────────────────────
1. Create AWS account
2. Create EKS Kubernetes cluster (15-20 min wait)
3. Setup MongoDB Atlas database
4. Build Docker image: docker build -t dalasmart-api:1.0.0 .
5. Push to DockerHub: docker push your-username/dalasmart-api:1.0.0
6. Deploy to Kubernetes: kubectl apply -f deployment.yaml
7. Setup domain & SSL certificate
8. ✅ API live at https://api.dalasmart.app

METHOD B: Using GitHub Actions (Automated)
────────────────────────────────────────────
1. Push code to GitHub
2. GitHub Actions automatically:
   - Runs tests
   - Builds Docker image
   - Pushes to registry
   - Deploys to Kubernetes
3. ✅ Live in ~5 minutes (zero-downtime)

================================================================================
                      QUICK COMMAND REFERENCE
================================================================================

ANDROID BUILD:
  cd apps/passenger-app
  npm run build:android --mode release

iOS BUILD:
  cd apps/passenger-app/ios
  xcodebuild -workspace DalaSmart.xcworkspace -scheme DalaSmart \
    -configuration Release archive

BACKEND BUILD:
  cd backend
  docker build -t dalasmart-api:1.0.0 .

DEPLOY TO KUBERNETES:
  kubectl apply -f deployment.yaml

CHECK DEPLOYMENT STATUS:
  kubectl get pods
  kubectl get services

VIEW LOGS:
  kubectl logs deployment/dalasmart-api

ROLLBACK IF NEEDED:
  kubectl rollout undo deployment/dalasmart-api
