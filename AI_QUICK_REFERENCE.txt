================================================================================
🆘 TROUBLESHOOTING
================================================================================

Issue: "ModuleNotFoundError: No module named 'fastapi'"
Solution: pip install -r requirements.txt

Issue: "Connection refused on port 8001"
Solution: AI Engine not running. Run: python -m uvicorn app.main:app --reload

Issue: "Cannot connect to Redis"
Solution: Redis not running. Start with: redis-server

Issue: "Google Cloud Vision API error"
Solution: Set GOOGLE_CLOUD_CREDENTIALS env variable

Issue: "Model file not found"
Solution: Create models/ directory or train models

For detailed troubleshooting → See AI_ENGINE_INTEGRATION.md
